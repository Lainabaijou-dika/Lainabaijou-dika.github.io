// 07 — Veille

Veille Technologique

Suivi sur 18 mois (octobre 2024 — mars 2026) des évolutions de l'Intelligence Artificielle dans le développement logiciel.

🤖 L'IA dans le développement logiciel — 18 mois de veille

Sujet suivi d'octobre 2024 à mars 2026. L'intelligence artificielle générative a profondément transformé les pratiques de développement logiciel. Des outils comme GitHub Copilot, ChatGPT, Gemini ou Claude sont désormais intégrés au quotidien des développeurs pour générer du code, détecter des bugs et automatiser des tâches répétitives.

📅 Évolution sur 18 mois

Oct. — Déc. 2024
Émergence des assistants IA

GitHub Copilot devient incontournable. Sortie de GPT-4o et intégration dans VS Code. Les développeurs commencent à adopter massivement l'autocomplétion intelligente.

Jan. — Avr. 2025
Montée en puissance des LLMs

Claude 3.5, Gemini 2.0, GPT-4.5 : la concurrence s'intensifie. Apparition des premiers agents IA capables de coder des projets entiers de façon autonome.

Mai — Sept. 2025
IA agents & automatisation

Les agents IA (Cursor, Devin, Claude Code) gèrent des tâches complexes : refactorisation, tests, déploiement. Le développement low-code assisté par IA explose.

Oct. 2025 — Mars 2026
IA dans les métiers SIO

Intégration dans les formations BTS SIO. Copilot dans GitHub Education. Débat sur les compétences attendues pour les futurs développeurs face à l'IA omniprésente.

✅ Avantages observés

  • Productivité ×2 — Autocomplétion intelligente (Copilot, Tabnine)
  • Qualité du code — Détection de bugs en temps réel, refactorisation
  • Automatisation — Tests unitaires, documentation, CI/CD assisté
  • Accessibilité — Les débutants progressent plus vite
  • Innovation — Chatbots, NLP, recommandations développés rapidement

⚠️ Limites & risques identifiés

  • Dépendance — Perte possible des compétences fondamentales
  • Fiabilité — Code généré parfois erroné, relecture indispensable
  • RGPD — Confidentialité des données soumises aux IA
  • Emploi — Automatisation des postes juniors, évolution du métier
  • Sécurité — Failles (injections SQL, XSS) non détectées par l'IA
